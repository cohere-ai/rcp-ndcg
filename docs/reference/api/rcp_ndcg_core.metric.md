# `rcp_ndcg_core.metric`

nDCG with float gains and explicit tie rules (pure Python, no torch).

Every name below is pinned by `tests/contract/snapshots/python_api.json` (the `__all__` of the public
modules); this page is generated by `rcp-ndcg docs api --out docs/reference/api` and never edited by hand.

## `TieRule`

literal_alias — How documents with equal scores are ordered when a score mapping is scored.

```text
TieRule = 'doc_id_desc' | 'group_mean' | 'input_order'
```

## `dcg`

function — ``DCG@k = sum_{r=1..k} gain(r) / log2(r + 1)`` of gains already in rank order (best first).

```text
dcg(gains_in_rank_order: Sequence[float], k: int) -> float
```

## `discount`

function — The nDCG position discount ``1 / log2(rank + 1)``; ``rank`` counts from 1.

```text
discount(rank: int) -> float
```

## `ideal_dcg`

function — The DCG@k of ``gains`` sorted best first: the normaliser of :func:`ndcg`.

```text
ideal_dcg(gains: Iterable[float], k: int) -> float
```

## `ndcg`

function — nDCG@k with linear gains.

```text
ndcg(scores: Mapping[str, float] | Sequence[str], gains: Mapping[str, float], *, k: int = 10, ties: TieRule = 'group_mean', ideal: Iterable[float] | None = None) -> float
```

## `rank_by_score`

function — Order document ids by decreasing score with a deterministic tie-break.

```text
rank_by_score(scores: Mapping[str, float], *, ties: Literal['doc_id_desc', 'input_order'] = 'doc_id_desc') -> list[str]
```

## `tie_groups`

function — The documents grouped by equal score, the best score first; within a group, in the order of ``scores``.

```text
tie_groups(scores: Mapping[str, float]) -> list[list[str]]
```
